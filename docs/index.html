Self-operated creator tool

Evidence before upload.

Beyond The Rules Uploader is a private production system used only by the owner of the YouTube channel 规则之外. It researches, rights-checks, renders, and uploads original Chinese documentary videos.

What the application does

  • Uses the narrow youtube.upload permission to upload videos to the channel owner's own account.
  • Does not read comments, subscriptions, analytics, contacts, email, or other Google account data.
  • Defaults every API upload to private while compliance review is pending.
  • Runs factual, media-license, format, and editorial checks before an upload is attempted.

Data handling

OAuth credentials are stored as encrypted GitHub Actions secrets and are exposed only to the private runtime job. They are not sold, shared, logged, or used for advertising. Generated production artifacts are retained for up to 30 days for quality review.
